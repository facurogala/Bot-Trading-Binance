## 🚀 Cómo Usar

Ejecuta cualquiera de estos bots:

```powershell
# Bot conservador con filtros estrictos
python auto_trading_scanner_conservador.py

# Bot normal
python auto_trading_scanner.py

# Bot de loop continuo
python scanner_loop.py

# Bot MACD (escaneo único)
python macd_scanner_once.py

# Wrappers (usan los bots principales)
python scanner_trading_conservador.py
python scanner_trading.py
python scanner_alertas.py
```

**Todos generarán reportes automáticamente** después de cada escaneo.
